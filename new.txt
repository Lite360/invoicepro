How it works end-to-end
User clicks "Upgrade" 
  → Paystack popup opens
  → User pays
  → Your frontend calls /api/payments/verify (immediate upgrade)
  → Paystack ALSO calls your webhook /api/payments/webhook (backup confirmation)
  → Both routes update user plan in database ✅
The webhook acts as a safety net — if the user closes the browser before your app can verify, Paystack will still call your server directly and upgrade the plan automatically. The webhook is secured with HMAC-SHA512 signature verification so nobody can fake a payment event.
